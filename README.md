# Compressor Balancer

Client-side (no backend) web app for mass properties and two-plane balancing of electric automotive
AC-compressor rotating assemblies. Work in progress — see CHANGELOG.md.

- Plain ES modules, no framework, no build step; deps vendored and pinned (see THIRD_PARTY.md).
- Run: any static server in the repo root (`python3 -m http.server`), or GitHub Pages.
- Test: `npm test` (Node ≥ 20, no dependencies).
